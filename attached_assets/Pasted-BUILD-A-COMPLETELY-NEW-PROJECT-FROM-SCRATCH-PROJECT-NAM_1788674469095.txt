==================================================
1. PROJECT GOAL
==================================================

Build a professional full-stack web application for B.Tech, college, and internship students.

The problem:
Students spend many hours manually understanding their project and preparing project/internship reports.

CodeGuard AI should allow a student to:

1. Upload their actual project as a ZIP.
2. Analyze and understand the project.
3. Display an accurate project summary.
4. Enter report requirements and student details.
5. Optionally upload a sample report PDF/DOCX.
6. Understand the sample report's structure.
7. Generate a professional report using AI based on the ACTUAL uploaded project.
8. Preview the generated report.
9. Edit the report.
10. Regenerate individual sections.
11. Download the final report as PDF and DOCX.

MAIN WORKFLOW:

Project ZIP
    ↓
Project Analysis
    ↓
Project Understanding
    ↓
Project Summary
    ↓
Report Instructions
    ↓

    ↓

    ↓
